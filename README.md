## L&FSWING - _School-Based Lost and Found Management System_

### Project Description

_A Java Swing desktop application using OOP and MySQL to manage lost-and-found item records._

L&FSWING is a desktop-based application using Java Swing. The system digitalizes the process of reporting, searching, and claiming lost items within the De La Salle Lipa campus. Instead of relying on traditional paper-based records, the application allows administrators to log and organize found items while enabling students to securely search and claim their belongings. Built with a user-friendly interface and backed by a MySQL database, the system improves efficiency, record management, and accessibility while maintaining safety and confidentiality for users.

### Technologies Used

- Java – Core programming language used for system development
- Java Swing (JFrame) – Used for building the graphical user interface (GUI)
- MySQL – Database used to store and manage lost and found records
- NetBeans IDE – Development environment used for building and testing the application
- Object-Oriented Programming (OOP) – Programming paradigm used for system design and structure

### Project Status

This project is completed as an academic project, a final major assessment CAPSTONE Project for the course Object-Oriented Programming, but may still receive improvements or refactoring in the future.
